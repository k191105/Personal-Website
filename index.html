01 / LOGIC
MODAL LOGIC · PYTORCH Exploratory research

Learning the shape of possible worlds

Can gradient descent search for a structure that makes a logical formula true? FrameLearner turns Kripke semantics into a differentiable model, letting the relations between possible worlds become learnable.

Read project notes +

From a formula to a frame

A Kripke frame describes worlds and which worlds are accessible from one another. I relax those relations into continuous values, then optimise them with fuzzy versions of the logical operators. An adversarial valuation searches for counterexamples while the relation learns to reduce logical loss.

What the experiment tells us

The small, eight-world experiments recover some recognisable frame structure, but low fuzzy loss is not a certificate of classical validity. Oscillation, degenerate solutions, and the need for a formal verification step remain central limitations. The interesting question is how the structure of an axiom affects the difficulty of learning its frame.

02 / LEARNING
REINFORCEMENT LEARNING · MODAL SEMANTICS In progress

Constraints an agent can learn with

A robot can earn its reward and still end up stuck. I’m investigating modal formulas as training constraints: a way to describe the structure of acceptable behaviour, including whether a charging station has an exit.

Read project notes +

A small world with a revealing failure

The proof of concept begins with a grid-world agent that can reach a charger but cannot escape it. The modal condition C → ◇¬Q expresses that a charger should have an accessible, unobstructed neighbour. A penalty based on this condition is incorporated into training.

Beyond the first example

The project extends the idea to uncertain maps and two-agent coordination. It is an investigation, not a demonstrated replacement for reward shaping: simple constraints can also be written as reward penalties, and systematic comparisons are still needed. My current research at CMU also explores probabilistic semantics for propositional dynamic logic through Markov decision processes.

03 / LANGUAGE
LANGUAGE MODELLING · PYTORCH Built from scratch

A language model with a personal reading list

I built a small language model to capture something of my intellectual profile, training it on thinkers and writers I enjoy: Russell, Bourdieu, Hofstadter, and Wilde, alongside my own essays. It’s a 25-million-parameter Llama-style model, built from scratch in PyTorch and trained on 1,941 books and essays.

Chat with the model — coming soon.

Read project notes +

Inside the implementation

The model brings together byte-pair encoding, rotary position embeddings, grouped-query attention, RMSNorm, SwiGLU, and AdamW. Training used 212 million tokens drawn from books and essays.

From text to transformer

This project follows the language-model pipeline all the way from the choice of text to the mechanics of a transformer. Its scale makes the components tangible: the tokenizer, architecture, and training corpus are parts of the same system.
