# Krishiv Singhal

A small, dependency-free personal website for GitHub Pages. Open `index.html` or serve this directory with a local HTTP server.

The project essays and background are in `index.html`, the visual design in `style.css`, and the SVG voxel illustrations in `script.js`. The site works without JavaScript; JavaScript only adds the decorative illustrations. Motion respects the visitor's reduced-motion preference.

## Publishing

Publish these files at the root of [`k191105/Personal-Website`](https://github.com/k191105/Personal-Website), then enable GitHub Pages from the `main` branch, root directory. The site address is [k191105.github.io/Personal-Website/](https://k191105.github.io/Personal-Website/). No build step or external services are required. All local asset links are relative so the site works at this repository path.

## Content sources

The supplied professional background and the public FrameLearner, ModalLogicRegularisedRL, Spectral-Experiments-in-Human-AI-Writing, and FO2-Presentation-Results repositories. Exploratory work is described as such; no performance comparisons or unsupported research claims are added.
