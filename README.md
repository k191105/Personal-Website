# Krishiv Singhal

A small, dependency-free personal website for GitHub Pages. Open `index.html` or serve this directory with a local HTTP server.

## Pages

- `index.html`: personal introduction, background, music links, and links into the work.
- `research.html`: modal logic, reinforcement learning, computational linguistics, and the two-variable logic talk.
- `projects.html`: the personal language model and Bitewise Labs apps.

Shared visual design lives in `style.css`; `script.js` adds voxel illustrations, a small world-turning interaction, and a light/dark theme switch. The text, navigation, and project notes remain available without JavaScript. Motion respects the visitor’s reduced-motion preference.

## Publishing

Publish the HTML pages, `style.css`, and `script.js` at the repository root, then enable GitHub Pages from the `main` branch and root directory. No build step is required. Relative links support both a repository site and a user site. The public address depends on the GitHub account and repository configuration; no canonical address is hard-coded.

Do not publish the local CV PDF. The site does not link it.

## Content sources

The supplied professional background, user-approved biographical updates, and the public FrameLearner, ModalLogicRegularisedRL, Spectral-Experiments-in-Human-AI-Writing, and FO2-Presentation-Results repositories. Exploratory work is described as such. The model chat is labelled coming soon until a real destination is available.
